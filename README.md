# hazemhijazi.github.io

My portfolio. Plain HTML and one CSS file, so there's nothing to install or build.

| File | What it is |
|---|---|
| `index.html` | Home: intro, the three case studies, about, contact |
| `work/design-system-leadership.html` | Case study 1 |
| `work/white-label-design-system.html` | Case study 2 |
| `work/luster.html` | Case study 3 (LUSTER) |
| `work/aounak.html` | Case study 4 |
| `assets/style.css` | All the styling. Change `--accent` at the top to change the colour |
| `assets/img/` | Images (`ao/` is AOUNAK) |
| `assets/Hazem_Hijazi_CV_2026.pdf` | My resume |

**To edit text:** open the HTML file in any editor and change the words.
**To swap the resume:** replace the PDF with a file of the same name.
**To publish:** upload everything to the `hazemhijazi.github.io` repository and commit.
